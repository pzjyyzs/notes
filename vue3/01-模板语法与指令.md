# Vue 3 模板语法与指令

> 本文覆盖 Vue 3 模板语法中所有常用指令，从语法到原理，从使用到面试。

---

## 一、插值表达式

### 1.1 `{{ }}` — Mustache 文本插值

```vue
<span>{{ message }}</span>
<span>你好，{{ name }}，欢迎回来</span>  <!-- 可和文本混用 -->
<span>{{ count + 1 }}</span>              <!-- 支持 JS 表达式 -->
<span>{{ ok ? '是' : '否' }}</span>       <!-- 三元表达式 -->
<span>{{ text.split('').reverse().join('') }}</span>  <!-- 方法调用 -->
```

**注意**：
- 只能写**单个表达式**，不能写语句（`{{ if (ok) {} }}` ❌）
- 不能写 `{{ var a = 1 }}`、`{{ return 1 }}`
- 表达式会在当前组件的作用域中求值

---

### 1.2 v-text — 设置 textContent

```vue
<span v-text="message"></span>
<!-- 等价于 <span>{{ message }}</span> -->
<!-- 但会替换元素内全部内容 -->
```

**与 `{{ }}` 的区别**：

| | `{{ }}` | `v-text` |
|------|:---:|:---:|
| 是否替换全部子内容 | ❌ 只替换占位位置 | ✅ 覆盖全部 |
| 能否和其他文本混用 | ✅ | ❌ |
| 安全性（不解析 HTML） | ✅ | ✅ |
| 使用频率 | 99% | 几乎不用 |

---

### 1.3 v-html — 设置 innerHTML

```vue
<div v-html="rawHtml"></div>
```

- **⚠️ XSS 风险**：不对用户输入直接使用 `v-html`
- 元素内的 Vue 模板语法不会生效
- 仅在渲染可信的富文本内容（如服务端返回的 HTML）时使用

```vue
<script setup>
const userInput = '<img src=x onerror="alert(\'XSS攻击!\')">';
const safeHtml = '<strong>可信的粗体文字</strong>';
</script>

<template>
  <p>{{ userInput }}</p>      <!-- ✅ 安全，显示纯文本 -->
  <p v-html="userInput"></p>  <!-- ❌ 危险！执行脚本 -->
  <p v-html="safeHtml"></p>   <!-- ✅ 可信来源 -->
</template>
```

---

### 1.4 v-pre — 跳过编译

```vue
<span v-pre>{{ 这里的 Mustache 标签不会被编译 }}</span>
<!-- 页面显示：{{ 这里的 Mustache 标签不会被编译 }} -->
```

使用场景：展示 Vue 模板代码、大量静态内容跳过编译提升性能。

---

### 1.5 v-once — 只渲染一次

```vue
<span v-once>这个值不会再改变：{{ count }}</span>
```

即使 `count` 后续变化，视图也不更新。用于静态内容的性能优化。

## 二、v-bind — 动态属性绑定

### 2.1 基本用法

```vue
<!-- 全写 -->
<a v-bind:href="url">链接</a>

<!-- 简写（几乎只用这个） -->
<a :href="url">链接</a>

<!-- 动态属性名 -->
<a :[attrName]="url">链接</a>

<!-- 布尔属性：true 时属性存在，false 时属性被移除 -->
<button :disabled="isDisabled">按钮</button>
```

---

### 2.2 class 绑定

```vue
<script setup>
const isActive = ref(true)
const hasError = ref(false)
const dynamicClass = 'highlight'
</script>

<template>
  <!-- 对象语法 -->
  <div :class="{ active: isActive, 'text-danger': hasError }"></div>

  <!-- 数组语法 -->
  <div :class="[isActive ? 'active' : '', dynamicClass]"></div>

  <!-- 混合 -->
  <div :class="[{ active: isActive }, dynamicClass]"></div>

  <!-- 和静态 class 共存 -->
  <div class="static" :class="{ active: isActive }"></div>
</template>
```

---

### 2.3 style 绑定

```vue
<script setup>
const activeColor = ref('red')
const fontSize = ref(14)
</script>

<template>
  <!-- 对象语法（推荐） -->
  <div :style="{ color: activeColor, fontSize: fontSize + 'px' }"></div>

  <!-- 驼峰写法 OK -->
  <div :style="{ backgroundColor: '#fff', marginTop: '10px' }"></div>

  <!-- 短横线写法也行（要加引号） -->
  <div :style="{ 'background-color': '#fff' }"></div>

  <!-- 数组语法：多个样式对象合并 -->
  <div :style="[baseStyles, overrideStyles]"></div>
</template>
```

Vue 会自动为 `transform`、`transition` 等自动添加浏览器前缀。

---

### 2.4 绑定多个属性

```vue
<script setup>
const attrs = {
  id: 'my-div',
  class: 'container',
  'data-tooltip': '提示文字'
}
</script>

<template>
  <!-- 一次性绑定对象的所有属性（Vue 3.2+） -->
  <div v-bind="attrs"></div>
</template>
```

## 三、v-model — 表单双向绑定

### 3.1 本质

```vue
<input v-model="text">
```

等价于：

```vue
<input
  :value="text"
  @input="text = $event.target.value"
>
```

---

### 3.2 不同表单元素

```vue
<script setup>
const text = ref('')
const checked = ref(false)
const checkedNames = ref([])
const picked = ref('')
const selected = ref('')
const multiSelected = ref([])
</script>

<template>
  <!-- 文本 -->
  <input v-model="text" />

  <!-- 多行文本 -->
  <textarea v-model="text"></textarea>

  <!-- 复选框（单个，布尔） -->
  <input type="checkbox" v-model="checked" />

  <!-- 复选框（多个，数组） -->
  <input type="checkbox" value="A" v-model="checkedNames" />
  <input type="checkbox" value="B" v-model="checkedNames" />

  <!-- 单选框 -->
  <input type="radio" value="选项1" v-model="picked" />

  <!-- 下拉（单选） -->
  <select v-model="selected">
    <option disabled value="">请选择</option>
    <option value="A">A</option>
    <option value="B">B</option>
  </select>

  <!-- 下拉（多选） -->
  <select v-model="multiSelected" multiple>
    <option value="A">A</option>
    <option value="B">B</option>
  </select>
</template>
```

---

### 3.3 修饰符

```vue
<!-- .lazy：change 事件后才更新（而非 input） -->
<input v-model.lazy="text" />

<!-- .number：自动转数字 -->
<input v-model.number="age" type="text" />

<!-- .trim：自动去除首尾空格 -->
<input v-model.trim="text" />
```

---

### 3.4 组件上的 v-model

```vue
<!-- 默认绑定 -->
<ChildComponent v-model="value" />
<!-- 等价于 -->
<ChildComponent :modelValue="value" @update:modelValue="value = $event" />

<!-- 子组件接收 -->
<script setup>
const props = defineProps(['modelValue'])
const emit = defineEmits(['update:modelValue'])
</script>

<!-- 命名的 v-model -->
<ChildComponent v-model:title="title" v-model:content="content" />
```

## 四、v-if — 条件渲染

```vue
<script setup>
const type = ref('A')
</script>

<template>
  <!-- 基本用法 -->
  <p v-if="score >= 60">及格</p>
  <p v-else-if="score >= 50">补考</p>
  <p v-else>不及格</p>

  <!-- 在 <template> 上使用，不产生额外 DOM -->
  <template v-if="type === 'A'">
    <h2>A 类型标题</h2>
    <p>A 类型内容</p>
  </template>
</template>
```

**`v-if` vs `v-show`**：

| | `v-if` | `v-show` |
|------|------|------|
| 原理 | 条件为假时**不渲染/销毁 DOM** | 始终渲染，通过 `display: none` 切换 |
| 初始开销 | 假时开销小 | 始终有初始渲染开销 |
| 切换开销 | 大（销毁/重建 DOM、重新执行生命周期） | 小（只切换 CSS） |
| 适用场景 | 条件很少变化 | 频繁切换（如 Tab 切换） |

---

**⚠️ `v-if` 和 `v-for` 不要在同一元素上使用**

> 因为在 Vue 3 中，`v-if` 的优先级高于 `v-for`，这意味着 `v-if` 中无法访问 `v-for` 的迭代变量。

```vue
<!-- ❌ 错误 -->
<li v-for="item in items" v-if="item.active">{{ item.name }}</li>

<!-- ✅ 正确：用 template 包一层 -->
<template v-for="item in items">
  <li v-if="item.active">{{ item.name }}</li>
</template>

<!-- ✅ 更好：用 computed 提前过滤 -->
<li v-for="item in activeItems">{{ item.name }}</li>
```

## 五、v-for — 列表渲染

### 5.1 基本用法

```vue
<script setup>
const items = ref([{ id: 1, name: 'A' }, { id: 2, name: 'B' }])
const obj = ref({ a: 1, b: 2, c: 3 })
</script>

<template>
  <!-- 数组：item, index -->
  <li v-for="(item, index) in items" :key="item.id">
    {{ index }} - {{ item.name }}
  </li>

  <!-- 对象：value, key, index -->
  <li v-for="(value, key, index) in obj" :key="key">
    {{ index }}. {{ key }}: {{ value }}
  </li>

  <!-- 数字：从 1 到 n -->
  <li v-for="n in 10" :key="n">{{ n }}</li>
</template>
```

---

### 5.2 `key` 为什么重要

```
key 是 Vue 虚拟 DOM diff 算法的核心依赖
- 有 key → 精准对比，最小化 DOM 操作
- 无 key → 原地复用，可能出现状态错乱（如输入框内容残留）
```

- `key` 应该是**唯一的、稳定的标识符**（如 `item.id`）
- **不要用 `index` 作为 key**（列表顺序变化时会导致错误的复用）

---

### 5.3 数组变更检测

```js
// ✅ 响应式方法（会触发视图更新）
push() / pop() / shift() / unshift() / splice() / sort() / reverse()

// ⚠️ 非响应式（需要替换引用）
filter() / concat() / slice()   // 返回新数组，要重新赋值
```

Vue 3 使用 Proxy，所以直接用 `arr[0] = newVal` 和 `arr.length = 0` 也是响应式的（Vue 2 不行）。

## 六、v-on — 事件处理

### 6.1 基本用法

```vue
<template>
  <!-- 全写 -->
  <button v-on:click="handleClick">按钮</button>

  <!-- 简写（最常用） -->
  <button @click="handleClick">按钮</button>

  <!-- 内联表达式 -->
  <button @click="count++">+1</button>

  <!-- 传递参数 -->
  <button @click="handleClick($event, '参数')">按钮</button>

  <!-- 动态事件名 -->
  <button @[eventName]="handleClick">按钮</button>
</template>
```

---

### 6.2 事件修饰符

```vue
<!-- .stop：阻止事件冒泡 -->
<div @click.stop="handleClick">点击</div>

<!-- .prevent：阻止默认行为 -->
<form @submit.prevent="onSubmit">提交</form>

<!-- .self：只在事件源是自身时触发 -->
<div @click.self="handleSelf">只有点我本身才触发</div>

<!-- .capture：使用捕获阶段 -->
<div @click.capture="handleClick">捕获阶段触发</div>

<!-- .once：只触发一次 -->
<button @click.once="handleOnce">只生效一次</button>

<!-- .passive：不阻止默认行为（用于滚动性能优化） -->
<div @scroll.passive="onScroll">滚动</div>

<!-- 链式调用（注意顺序有影响） -->
<a @click.stop.prevent="doSomething">阻止冒泡+阻止默认</a>
```

---

### 6.3 按键修饰符

```vue
<!-- 键盘事件 -->
<input @keyup.enter="submit" />       <!-- 回车 -->
<input @keyup.esc="close" />          <!-- Esc -->
<input @keyup.delete="remove" />      <!-- Delete / Backspace -->
<input @keyup.ctrl.s="save" />        <!-- Ctrl + S -->

<!-- 鼠标按钮修饰符 -->
<div @click.left="leftClick"></div>   <!-- 左键 -->
<div @click.right="rightClick"></div> <!-- 右键 -->
<div @click.middle="middleClick"></div><!-- 中键 -->

<!-- 系统修饰符（需按住才触发） -->
<button @click.ctrl="onCtrlClick">Ctrl+点击才触发</button>
<button @click.alt="onAltClick">Alt+点击才触发</button>
<button @click.shift="onShiftClick">Shift+点击才触发</button>

<!-- .exact：精确匹配 -->
<button @click.ctrl.exact="onCtrlOnly">仅 Ctrl（Ctrl+Shift 不触发）</button>
<button @click.exact="onNoModifier">无任何修饰键才触发</button>
```

## 七、v-slot — 插槽

### 7.1 基本用法

```vue
<!-- 父组件 -->
<ChildComponent>
  <p>这是插槽内容</p>
</ChildComponent>

<!-- 子组件 ChildComponent -->
<template>
  <slot>这是默认内容（父组件不传时显示）</slot>
</template>
```

---

### 7.2 具名插槽

```vue
<!-- 父组件 -->
<ChildComponent>
  <template v-slot:header>
    <h1>页头</h1>
  </template>

  <!-- 默认插槽可省略 template -->
  <p>主体内容</p>

  <!-- 简写：# -->
  <template #footer>
    <p>页脚</p>
  </template>
</ChildComponent>

<!-- 子组件 -->
<div>
  <slot name="header"></slot>
  <slot></slot>           <!-- 默认插槽 -->
  <slot name="footer"></slot>
</div>
```

---

### 7.3 作用域插槽

子组件向父组件暴露数据：

```vue
<!-- 子组件 -->
<script setup>
const items = ref([
  { id: 1, name: 'Apple' },
  { id: 2, name: 'Banana' },
])
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item.id">
      <slot name="item" :item="item" :index="index">
        <!-- 默认渲染 -->
        {{ item.name }}
      </slot>
    </li>
  </ul>
</template>

<!-- 父组件 -->
<ChildComponent>
  <template #item="{ item, index }">
    <strong>{{ index + 1 }}. {{ item.name }}</strong>
  </template>
</ChildComponent>
```

## 八、v-memo — 记忆化（Vue 3.2+）

```vue
<template>
  <!-- 只有依赖项变化时，才重新渲染这个子树的 VNode -->
  <div v-memo="[list.length]">
    <!-- 大量子节点，只在 list.length 变化时才更新 -->
    <ExpensiveChild v-for="item in list" :key="item.id" :item="item" />
  </div>
</template>
```

配合 `v-for` 使用：
```vue
<div v-for="item in list" :key="item.id" v-memo="[item.id === selectedId]">
  <!-- 只有当前项的选中状态变化时，才重新渲染 -->
</div>
```

## 九、自定义指令

### 9.1 基本用法

```js
// main.js 全局注册
app.directive('focus', {
  mounted(el) {
    el.focus()
  }
})
```

```vue
<!-- 使用 -->
<input v-focus />
```

---

### 9.2 指令钩子（与组件生命周期对应）

```
created     → 在元素属性/事件绑定前调用
beforeMount → 元素挂载前
mounted     → 父组件及子元素挂载完成后
beforeUpdate → 元素更新前
updated     → 父组件及子元素更新后
beforeUnmount → 元素卸载前
unmounted   → 元素卸载后
```

```js
app.directive('example', {
  created(el, binding, vnode) {},
  beforeMount(el, binding, vnode) {},
  mounted(el, binding, vnode, prevVnode) {},
  beforeUpdate(el, binding, vnode, prevVnode) {},
  updated(el, binding, vnode, prevVnode) {},
  beforeUnmount(el, binding, vnode) {},
  unmounted(el, binding, vnode) {},
})
```

---

### 9.3 指令参数

```vue
<!-- binding 对象 -->
<div v-my-directive:arg.mod1.mod2="value">
<!--
  binding.value   → 'value' 的值
  binding.arg     → 'arg'（动态参数）
  binding.modifiers → { mod1: true, mod2: true }
-->
```

---

### 9.4 指令简写

如果只关心 `mounted` 和 `updated`（最常见的场景），可以用简写：

```js
app.directive('highlight', (el, binding) => {
  // 在 mounted 和 updated 时都执行
  el.style.backgroundColor = binding.value
})
```

## 十、总结速查表

| 指令 | 简写 | 用途 | 常见修饰符 |
|------|:---:|------|------|
| `v-bind` | `:` | 动态属性绑定 | `.attr` `.prop` `.camel` |
| `v-model` | — | 双向数据绑定 | `.lazy` `.number` `.trim` |
| `v-on` | `@` | 事件绑定 | `.stop` `.prevent` `.self` `.once` `.passive` `.capture` + 按键/鼠标修饰符 |
| `v-if` / `v-else-if` / `v-else` | — | 条件渲染（销毁/重建） | — |
| `v-show` | — | 条件显示（CSS 切换） | — |
| `v-for` | — | 列表渲染 | 必须搭配 `:key` |
| `v-slot` | `#` | 插槽 | 具名插槽、作用域插槽 |
| `v-html` | — | 渲染 HTML | ⚠️ XSS 风险 |
| `v-text` | — | 渲染纯文本（几乎不用） | — |
| `v-pre` | — | 跳过编译 | — |
| `v-once` | — | 只渲染一次 | — |
| `v-memo` | — | 记忆化子树 | — |
| `v-cloak` | — | 隐藏未编译的模板（全屏 loading 用） | — |

## 十一、面试重点

1. **`v-if` 和 `v-show` 的区别**
   — 答：DOM 销毁 vs CSS 隐藏；初始开销 vs 切换开销

2. **`v-if` 和 `v-for` 为什么不能同时用**
   — 答：Vue 3 中 `v-if` 优先级更高，无法访问 `v-for` 的变量

3. **`v-model` 的本质**
   — 答：`:value` + `@input` 的语法糖

4. **事件修饰符 `.passive` 的作用**
   — 答：告诉浏览器不会 `preventDefault()`，可以立即滚动，不等待 JS 执行

5. **`key` 的作用**
   — 答：虚拟 DOM diff 时判断节点是否可复用，必须唯一且稳定

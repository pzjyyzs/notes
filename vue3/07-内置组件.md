# Vue 3 内置组件

> Vue 提供了 6 个内置组件，不需要注册即可在模板中使用。它们解决的是通用且高频的需求：缓存、传送、
> 异步加载、动画。

---

## 一、内置组件总览

| 组件 | 一句话作用 | 使用频率 |
|------|------|:---:|
| `<KeepAlive>` | 缓存组件实例，切换不销毁 | ⭐⭐⭐⭐⭐ |
| `<Teleport>` | 把内容传送到 DOM 任意位置 | ⭐⭐⭐⭐ |
| `<Suspense>` | 管理异步组件的加载状态 | ⭐⭐⭐ |
| `<Transition>` | 单个元素/组件的进入离开动画 | ⭐⭐⭐⭐ |
| `<TransitionGroup>` | 列表的增删移动动画 | ⭐⭐⭐ |
| `<component :is>` | 动态切换组件 | ⭐⭐⭐⭐⭐ |

## 二、KeepAlive — 组件缓存

### 2.1 作用

包裹动态组件时，**缓存不活动的组件实例，而不是销毁它们**。

```
没有 KeepAlive：
  切走 → 组件销毁（状态全丢）→ 切回 → 重新创建（重新请求、重新渲染）

有 KeepAlive：
  切走 → 组件缓存（状态保留）→ 切回 → 直接激活（瞬间恢复）
```

---

### 2.2 三个属性

```vue
<template>
  <KeepAlive
    include="UserList,UserDetail"  <!-- 只缓存这些（按组件 name 匹配） -->
    exclude="HeavyChart"           <!-- 不缓存这些 -->
    :max="10"                      <!-- 最多缓存 10 个，LRU 淘汰 -->
  >
    <component :is="currentView" />
  </KeepAlive>
</template>
```

---

### 2.3 专属生命周期

被 KeepAlive 包裹的组件会多两个钩子：

```vue
<script setup>
import { onActivated, onDeactivated } from 'vue'

onActivated(() => {
  // 从缓存中恢复（替代 onMounted）
  console.log('组件被激活了')
})

onDeactivated(() => {
  // 被缓存起来（替代 onUnmounted）
  console.log('组件被缓存了')
})
</script>
```

**注意**：缓存的组件 `onUnmounted` 不会触发，直到真正被销毁。

---

### 2.4 典型场景

**Tab 切换保留表单状态：**

```vue
<script setup>
import { ref } from 'vue'
const activeTab = ref('info')
</script>

<template>
  <button @click="activeTab = 'info'">基本信息</button>
  <button @click="activeTab = 'setting'">设置</button>

  <KeepAlive>
    <UserInfo v-if="activeTab === 'info'" />
    <UserSetting v-else-if="activeTab === 'setting'" />
  </KeepAlive>
</template>
```

**路由缓存（最常用）：**

```vue
<template>
  <KeepAlive :include="['PostList']">
    <router-view />
  </KeepAlive>
</template>
```

---

### 2.5 原理简述

```
内部维护两个数据结构：
  cache: Map<key, VNode>     → 缓存组件实例
  keys:  Set<key>            → 用于 LRU 淘汰计算

命中缓存：直接复用 VNode，触发 onActivated
超出 max：删除 keys 中最早加入的，对应 cache 也被清除
```

## 三、Teleport — 传送门

### 3.1 解决的问题

前端开发中很多 UI 组件在逻辑上属于当前组件，但在 DOM 层级上应该挂载到外层（如 `body` 下），避免被父元素的 CSS（overflow、z-index、position）影响。

```
常见场景：Modal、Dialog、Toast、Dropdown、Tooltip
```

---

### 3.2 基本用法

```vue
<template>
  <button @click="show = true">打开弹窗</button>

  <!-- 这个弹窗会被传送到 body 下 -->
  <Teleport to="body">
    <div v-if="show" class="modal">
      <p>这是一个模态框</p>
      <button @click="show = false">关闭</button>
    </div>
  </Teleport>
</template>
```

**渲染结果**：`.modal` 出现在 `<body>` 的直接子元素位置，但**逻辑上仍然是当前组件的子组件**——props、emits、provide/inject 照常工作。

---

### 3.3 `to` 属性的多种写法

```vue
<!-- CSS 选择器 -->
<Teleport to="body">

<!-- 特定元素 -->
<Teleport to="#modal-container">

<!-- data 属性 -->
<Teleport to="[data-teleport-target]">
```

对应 DOM：

```html
<!-- index.html -->
<body>
  <div id="app"></div>
  <div id="modal-container"></div>  <!-- 弹窗会传送到这里 -->
</body>
```

---

### 3.4 条件禁用

```vue
<script setup>
const enableTeleport = ref(true)
</script>

<template>
  <Teleport to="body" :disabled="!enableTeleport">
    <div class="modal">...</div>
  </Teleport>
</template>
```

`:disabled="true"` 时，内容渲染在原位置，相当于没写 `<Teleport>`。

---

### 3.5 多个 Teleport 到同一目标

```vue
<Teleport to="#toast-container">
  <div class="toast">第一条消息</div>
</Teleport>

<Teleport to="#toast-container">
  <div class="toast">第二条消息</div>
</Teleport>

<!-- 渲染结果：#toast-container 中按书写顺序排列 -->
<!-- 两个 .toast 都会出现在目标容器中 -->
```

## 四、Suspense — 异步加载管理

### 4.1 解决的问题

管理**异步组件**的加载状态，在加载完成前显示 fallback 内容。

在 Vue 3 中，异步组件有两种：`defineAsyncComponent` 和 `<script setup>` 中使用顶层 `await`。

---

### 4.2 基本用法

```vue
<template>
  <Suspense>
    <!-- 加载完成后显示 -->
    <template #default>
      <AsyncDashboard />
    </template>

    <!-- 加载中显示 -->
    <template #fallback>
      <div class="loading-skeleton">
        <p>加载中...</p>
      </div>
    </template>
  </Suspense>
</template>

<script setup>
import { defineAsyncComponent } from 'vue'

const AsyncDashboard = defineAsyncComponent(() =>
  import('./Dashboard.vue')
)
</script>
```

---

### 4.3 多个异步组件

```vue
<template>
  <!-- Suspense 会等待 default 插槽中所有异步组件加载完 -->
  <!-- 全部加载完成后才一起显示 -->
  <Suspense>
    <template #default>
      <AsyncHeader />    <!-- 异步 -->
      <AsyncContent />   <!-- 异步 -->
      <AsyncSidebar />   <!-- 异步 -->
    </template>
    <template #fallback>
      <Loading />
    </template>
  </Suspense>
</template>
```

> `Suspense` 会等 `#default` 插槽中**所有**异步依赖都 resolve 后才显示。

---

### 4.4 错误处理

Suspense 可以配合 `onErrorCaptured` 或 `<ErrorBoundary>` 处理加载失败：

```vue
<template>
  <Suspense @pending="loading = true" @resolve="loading = false">
    <template #default>
      <AsyncComponent />
    </template>
    <template #fallback>
      <Loading />
    </template>
  </Suspense>
</template>
```

三个事件：

| 事件 | 说明 |
|------|------|
| `@pending` | 进入挂起状态（开始加载） |
| `@resolve` | default 插槽内容解析完成 |
| `@fallback` | 显示 fallback 内容时触发 |

---

### 4.5 Suspense 改变生命周期

使用 Suspense 后，**组件的生命周期会等到异步依赖 resolve 后才继续**：

```vue
<script setup>
// 有顶层 await
const data = await fetch('/api/data')  // ← await 完成前，组件不会进入 onMounted

import { onMounted } from 'vue'
onMounted(() => {
  console.log('等到 await 完成后才执行')
})
</script>
```

## 五、Transition — 过渡动画

### 5.1 核心概念

`<Transition>` 会自动给包裹的元素在**不同阶段**添加/移除 CSS class，你只需写 CSS 即可。

**使用条件（三选一）**：
1. `v-if` — 条件渲染的切换
2. `v-show` — 条件显示的切换
3. `<component :is>` — 动态组件切换

---

### 5.2 六个过渡 class

```
进入（Enter）：
  .v-enter-from    →  开始状态（第一帧后移除）
       │
  .v-enter-active  →  过渡过程中一直存在
       │
  .v-enter-to      →  结束状态（过渡结束后移除）

离开（Leave）：
  .v-leave-from    →  开始状态
       │
  .v-leave-active  →  过渡过程中一直存在
       │
  .v-leave-to      →  结束状态
```

```vue
<template>
  <button @click="show = !show">切换</button>

  <Transition name="fade">
    <p v-if="show">Hello Vue</p>
  </Transition>
</template>

<style>
/* name="fade"，class 前缀变为 fade- */
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.5s ease;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
</style>
```

---

### 5.3 命名过渡

```vue
<!-- 不同的 name，对应不同的 CSS class 前缀 -->
<Transition name="slide"> ... </Transition>
<!-- CSS：.slide-enter-active { ... } -->

<Transition name="zoom"> ... </Transition>
<!-- CSS：.zoom-enter-active { ... } -->
```

---

### 5.4 自定义过渡 class

当你想用第三方动画库时（如 Animate.css）：

```vue
<Transition
  enter-active-class="animate__animated animate__fadeIn"
  leave-active-class="animate__animated animate__fadeOut"
>
  <p v-if="show">内容</p>
</Transition>
```

---

### 5.5 JavaScript 钩子

```vue
<template>
  <Transition
    @before-enter="onBeforeEnter"
    @enter="onEnter"
    @after-enter="onAfterEnter"
    @before-leave="onBeforeLeave"
    @leave="onLeave"
    @after-leave="onAfterLeave"
  >
    <p v-if="show">内容</p>
  </Transition>
</template>

<script setup>
// 用 JS 实现复杂动画（如 GSAP）
function onEnter(el, done) {
  gsap.to(el, {
    opacity: 1,
    duration: 0.3,
    onComplete: done  // ← 调用 done 告诉 Vue 动画结束
  })
}

function onLeave(el, done) {
  gsap.to(el, {
    opacity: 0,
    duration: 0.3,
    onComplete: done
  })
}
</script>
```

**关键**：`done()` 回调是告诉 Vue 动画结束的**唯一方式**。不调用 `done()`，Vue 不知道动画何时结束。

---

### 5.6 mode — 切换模式

```vue
<!-- 默认：旧元素离开和新元素进入同时进行 -->
<Transition>

<!-- out-in：旧元素先离开，新元素再进入（推荐） -->
<Transition mode="out-in">

<!-- in-out：新元素先进入，旧元素再离开 -->
<Transition mode="in-out">
```

---

### 5.7 appear — 初次渲染也执行动画

```vue
<Transition appear>
  <p>页面加载时我就会执行进入动画</p>
</Transition>
```

## 六、TransitionGroup — 列表动画

### 6.1 基本用法

```vue
<template>
  <button @click="add">+ 添加</button>

  <TransitionGroup name="list" tag="ul">
    <li v-for="item in items" :key="item.id">
      {{ item.text }}
      <button @click="remove(item.id)">×</button>
    </li>
  </TransitionGroup>
</template>

<style>
.list-enter-active,
.list-leave-active {
  transition: all 0.5s ease;
}
.list-enter-from {
  opacity: 0;
  transform: translateX(30px);
}
.list-leave-to {
  opacity: 0;
  transform: translateX(-30px);
}
/* ⚠️ 关键：离开的元素脱离文档流，让其他元素平滑移动 */
.list-leave-active {
  position: absolute;
}
/* 其他元素移动时也要有过渡 */
.list-move {
  transition: transform 0.5s ease;
}
</style>
```

---

### 6.2 v-move — 列表移动动画

```
当列表中有元素被添加或移除时，其余元素的位置会改变。
.v-move 就是控制这些「被挤开」元素的过渡动画。

没有 .list-move { transition: transform 0.3s }
  → 其他元素直接跳到新位置（突兀）

有 .list-move { transition: transform 0.3s }
  → 其他元素平滑移动到新位置（流畅）
```

---

### 6.3 FLIP 原理

TransitionGroup 使用 **FLIP** 技术实现平滑移动：

```
First  — 记录元素移动前的位置
Last   — 记录元素移动后的位置
Invert — 计算位移差，用 transform 反向偏移
Play   — 移除 transform，加上 transition，元素平滑到达新位置
```

这是纯 CSS 无法做到的——TransitionGroup 用 JS 在内部帮你处理了。

---

### 6.4 与 Transition 的区别

| | Transition | TransitionGroup |
|------|:---:|:---:|
| 包裹元素个数 | 单个 | 多个（列表） |
| 渲染为真实元素 | ❌（不渲染 DOM） | ✅（默认渲染 `<span>`，可用 `tag` 指定） |
| 元素用 key 标识 | ❌ | ✅ 必须要有 key |
| 支持 v-move | ❌ | ✅（FLIP 动画） |
| CSS class | 仅作用于每个元素 | 作用于每个元素 + `.v-move` 作用于位移元素 |

## 七、component :is — 动态组件

### 7.1 基本用法

```vue
<template>
  <!-- 根据 currentTab 的值动态切换组件 -->
  <component :is="currentTab" />
</template>

<script setup>
import { ref } from 'vue'
import TabA from './TabA.vue'
import TabB from './TabB.vue'

const currentTab = ref(TabA)  // 直接传组件对象
</script>
```

---

### 7.2 `:is` 接受的值

```vue
<!-- ① 组件对象（最常用） -->
<component :is="SomeComponent" />

<!-- ② 字符串（注册过的组件名） -->
<component :is="'MyComponent'" />

<!-- ③ 原生 HTML 元素 -->
<component :is="'h1'">标题</component>
<!-- 渲染为 <h1>标题</h1> -->

<component :is="'a'" href="/link">链接</component>
<!-- 渲染为 <a href="/link">链接</a> -->
```

---

### 7.3 配合 KeepAlive

```vue
<template>
  <KeepAlive>
    <component :is="currentView" />
  </KeepAlive>
</template>

<script setup>
import { computed, ref } from 'vue'

const currentTab = ref('home')
const tabs = {
  home: () => import('./Home.vue'),     // 异步组件 + KeepAlive 缓存
  about: () => import('./About.vue'),
  settings: () => import('./Settings.vue'),
}

const currentView = computed(() =>
  defineAsyncComponent(tabs[currentTab.value])
)
</script>
```

## 八、实战：构建 Tab 切换（整合 KeepAlive + Transition + component）

```vue
<script setup>
import { ref, defineAsyncComponent } from 'vue'

const tabs = [
  { key: 'posts', label: '文章', component: defineAsyncComponent(() => import('./PostsTab.vue')) },
  { key: 'users', label: '用户', component: defineAsyncComponent(() => import('./UsersTab.vue')) },
  { key: 'settings', label: '设置', component: defineAsyncComponent(() => import('./SettingsTab.vue')) },
]

const activeKey = ref('posts')
const currentComponent = computed(() =>
  tabs.find(t => t.key === activeKey.value)?.component
)
</script>

<template>
  <div class="tabs">
    <button
      v-for="tab in tabs"
      :key="tab.key"
      :class="{ active: activeKey === tab.key }"
      @click="activeKey = tab.key"
    >
      {{ tab.label }}
    </button>
  </div>

  <div class="tab-content">
    <Suspense>
      <template #default>
        <KeepAlive>
          <Transition name="fade" mode="out-in">
            <component :is="currentComponent" :key="activeKey" />
          </Transition>
        </KeepAlive>
      </template>
      <template #fallback>
        <div class="skeleton">加载中...</div>
      </template>
    </Suspense>
  </div>
</template>

<style>
.fade-enter-active,
.fade-leave-active {
  transition: opacity 0.2s ease;
}
.fade-enter-from,
.fade-leave-to {
  opacity: 0;
}
.tab-content {
  position: relative;
}
.active {
  color: #42b883;
  border-bottom: 2px solid #42b883;
}
</style>
```

## 九、面试题

### 1. KeepAlive 的原理是什么？

> 内部维护 `Map<key, VNode>` 缓存组件实例。切换时先查缓存，命中则直接复用，不重新创建。通过 `max` + LRU（最近最少使用）算法淘汰过期实例。命中缓存时设置 `ShapeFlags.COMPONENT_KEPT_ALIVE` 标记，触发 `onActivated` 而非 `onMounted`。

---

### 2. Teleport 和普通渲染有什么不同？

> 普通渲染：组件渲染的 DOM 在组件树的原始位置，受父元素 CSS 影响。
> Teleport：DOM 被传送到指定目标下（如 `<body>`），但组件逻辑（props、事件、provide/inject）保持原样。
>
> 解决的核心问题：Modal/Toast 等需要"脱离"父容器 CSS 约束的场景。

---

### 3. Transition 的六个 class 和触发时机？

> - `v-enter-from`：进入前（第一帧后移除）
> - `v-enter-active`：进入过程中（全程）
> - `v-enter-to`：进入后（过渡结束后移除）
> - `v-leave-from`：离开前
> - `v-leave-active`：离开过程中（全程）
> - `v-leave-to`：离开后

---

### 4. Transition 和 TransitionGroup 的区别？

> Transition 用于单个元素（v-if/v-show/动态组件），不渲染真实 DOM 元素。
> TransitionGroup 用于列表（v-for），渲染为真实元素（默认 `<span>`），必须加 key，支持 v-move 实现 FLIP 动画。

---

### 5. Suspense 怎么处理加载和错误？

> `#default` 插槽放异步组件，`#fallback` 插槽放加载状态。
> 用 `@pending` / `@resolve` / `@fallback` 事件监听状态变化。
> 错误处理需要配合 `onErrorCaptured` 自定义错误边界。

---

## 十、总结

```
KeepAlive        → 缓存不销毁，切换秒开。属性 include/exclude/max
Teleport         → 传送到任意 DOM。属性 to/disabled
Suspense         → 异步加载管理。插槽 #default/#fallback
Transition       → 单元素过渡。六 class + JS 钩子 + mode
TransitionGroup  → 列表过渡。多 .v-move（FLIP）
component :is    → 动态切换。配 KeepAlive + Transition 效果最佳
```
